# Sorare Football Overlay 0.4.16 – Matchbalken-Hotfix

## Chrome Web Store

**[Zur Store-Version](https://chromewebstore.google.com/detail/sorare-football-stats-ove/ddolakmpillologhigdmolbbmfphakjm)**

Die Store-Version erhält Updates automatisch. 0.4.16 ist dort erst nach
Einreichung und Freigabe durch Google verfügbar; bis dahin kann noch eine
ältere Version angeboten werden. Das fertige Paket für die manuelle
Installation findest du unten unter **Assets**.

## Bugfixes

- **Keine doppelten Matchbalken:** Der neue Sorare-Balken wird ausgeblendet,
  sobald unser Overlay einen eigenen Matchbalken anzeigt. Fehlen uns die
  Werte oder ist das Overlay ausgeschaltet, bleibt Sorare sichtbar.
- **Quoten bei Länderspielen:** Vorhandene Match- und Clean-Sheet-Quoten werden
  jetzt dem richtigen Nationalteam zugeordnet, statt an der Vereinszuordnung
  des Spielers hängen zu bleiben.

Die Korrektur für Länderspiele ist bereits im Statistikdienst aktiv. Für die
neue Balkendarstellung bitte die Erweiterung aktualisieren. Es sind keine
neuen Browserberechtigungen erforderlich.

## Manuell installieren oder aktualisieren

1. Unter **Assets** die Datei
   `sorare-football-overlay-chrome-web-store-0.4.16.zip` herunterladen –
   **nicht** die Datei **Source code (zip)**.
2. Die ZIP in einen dauerhaften Ordner entpacken. Bei einem Update die
   bisherigen Erweiterungsdateien durch die neuen ersetzen.
3. `chrome://extensions` oder `edge://extensions` öffnen.
4. Bei einer Erstinstallation den **Entwicklermodus** aktivieren und
   **Entpackte Erweiterung laden** wählen. Bei einem Update **Neu laden** anklicken.
5. Geöffnete Sorare-Seiten einmal aktualisieren.

[Ausführliche Installations- und Update-Anleitung](https://github.com/Grooverbeck/sorare-football-overlay/blob/v0.4.16/docs/INSTALLATION.md)

Store- und manuelle Version nicht gleichzeitig aktivieren, damit Anzeigen
nicht doppelt erscheinen. Die Verfügbarkeit von Quoten hängt weiterhin von
der Begegnung und den Datenquellen ab.

Unabhängige, inoffizielle Erweiterung für Google Chrome und Microsoft Edge –
kein Produkt von Sorare.

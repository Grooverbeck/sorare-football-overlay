# Sorare Football Overlay 0.4.14

## Verbesserungen

- **Passendere Farben für das europäische Set:** Die Farbstufen für Tor- und
  Assistquoten orientieren sich jetzt an Spielern aus Premier League,
  Bundesliga, LaLiga und Ligue 1. Historische Ersatzwerte haben weiterhin
  eine eigene, ebenfalls aktualisierte Farbskala. Die Prozentwerte selbst
  ändern sich dadurch nicht.

## Bugfixes

- **Richtige AA-Werte bei ausgewählten Spielern:** Bereits belegte Positionen
  im Lineup werden zuverlässiger erkannt. Dadurch werden beispielsweise
  Stürmer nicht mehr versehentlich wie Verteidiger ausgewertet.
- **Verbesserte Erkennung von Videokarten:** Videokarten werden in weiteren
  Fällen zuverlässiger erkannt, auch über Namen in ihren Ladeplatzhaltern.

## Installation und Update

Bei einer Installation aus dem Chrome Web Store wird das Update nach der
Freigabe durch Google automatisch verteilt. Offene Sorare-Seiten anschließend
einmal aktualisieren.

Für manuelle Installationen die ZIP
`sorare-football-overlay-chrome-web-store-0.4.14.zip` entpacken, den Inhalt
in den bisherigen Erweiterungsordner kopieren und die Erweiterung unter
`chrome://extensions` oder `edge://extensions` neu laden. Danach offene
Sorare-Tabs aktualisieren. GitHub-Archive namens **Source code** sind nicht
das installierbare Erweiterungspaket.

Weitere Hinweise: [Installation und Updates](INSTALLATION.md).

Die Verfügbarkeit von Marktquoten hängt weiterhin vom Spieler, der Begegnung
und den Datenquellen ab. Unabhängige, inoffizielle Erweiterung – kein Produkt
von Sorare. Dieses Update benötigt keine neuen Berechtigungen.

# Sorare Football Overlay 0.4.17 – Länderspiele im Blick

[Zur Store-Seite](https://chromewebstore.google.com/detail/sorare-football-stats-ove/ddolakmpillologhigdmolbbmfphakjm) · Die Freigabe von 0.4.17 im Store erfolgt separat. Bis dahin kann dort noch eine ältere Version stehen.

## Neu

- **AA passend zum nächsten Spiel:** Steht ein Länderspiel an, zeigt das Overlay die AA aus Einsätzen für die Nationalmannschaft. Vor Vereinsspielen zeigt es wieder die Vereins-AA. Beide Werte bleiben erhalten; der Hinweis an der Karte erklärt, welche Spiele zählen.
- **Quoten für die Nations League früher sichtbar:** Verfügbare Tor- und Assistquoten können nun schon bis zu vier Tage vor dem Spiel erscheinen.

## Verbessert

- **Vollständiger nach AA sortieren:** Auch in großen Spielerlisten werden neu geladene Nationalteamwerte berücksichtigt, damit passende Karten nicht am Ende der Liste übersehen werden.
- **Werte bleiben beim Nachladen erhalten:** Eine vorübergehend fehlgeschlagene Abfrage ersetzt keine bereits vorhandenen AA-Werte.

Der Statistikdienst ist aktualisiert. Für die neue AA-Anzeige und Sortierung braucht die Browser-Erweiterung dieses Update. Neue Browserberechtigungen sind nicht erforderlich.

## Manuell installieren oder aktualisieren

1. Unter **Assets** `sorare-football-overlay-chrome-web-store-0.4.17.zip` herunterladen – nicht **Source code (zip)**.
2. Die ZIP in einen dauerhaften Ordner entpacken. Bei einem Update die bisherigen Erweiterungsdateien durch die neuen ersetzen.
3. `chrome://extensions` oder `edge://extensions` öffnen. Bei einer Erstinstallation den Entwicklermodus einschalten und **Entpackte Erweiterung laden** wählen; bei einem Update **Neu laden** anklicken.
4. Geöffnete Sorare-Seiten einmal aktualisieren.

[Ausführliche Installationsanleitung](https://github.com/Grooverbeck/sorare-football-overlay/blob/v0.4.17/docs/INSTALLATION.md)

Store- und manuelle Version nicht gleichzeitig aktivieren, damit Anzeigen nicht doppelt erscheinen. Welche Quoten verfügbar sind, hängt von Spiel und Datenanbieter ab.

Unabhängige, inoffizielle Erweiterung für Google Chrome und Microsoft Edge – kein Produkt von Sorare.
